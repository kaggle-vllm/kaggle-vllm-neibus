# Limitations

- The local app layer is not an inference engine.
- Nemotron recommendations can be wrong; policy validation and measured reruns
  are required.
- The project does not claim that Nemotron 3.5 Lightning runs on Kaggle T4.
- The project does not claim universal TP speedups.
- `artifacts/demo` remains synthetic/illustrative; real checksummed evidence is
  separately labeled under `artifacts/public`.
- The real M2 matrix demonstrates deterministic import and analysis, but no new
  recommendation-specific rerun has yet been claimed as verified.
- The application has no Nebius AI Cloud GPU execution backend today.
- A public hosted demo URL and public three-minute YouTube video remain pending.
