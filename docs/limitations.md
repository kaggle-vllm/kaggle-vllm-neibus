# Limitations

- The local app layer is not an inference engine.
- Nemotron recommendations can be wrong; policy validation and measured reruns
  are required.
- The project does not claim that Nemotron 3.5 Lightning runs on Kaggle T4.
- The project does not claim universal TP speedups.
- Demo fixture values in `artifacts/demo` are illustrative until replaced with
  real checksummed benchmark outputs.
