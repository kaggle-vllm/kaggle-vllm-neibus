# Demo plan

The three-minute demo should show one real problem end-to-end:

1. Show dual-T4 environment.
2. Import the checksummed real Qwen TP matrix.
3. Show Python calculate the first measured TP crossover.
4. Ask: "Why does TP=2 change from slower to faster as concurrency rises?"
5. Show Nemotron invoking read-only tools.
6. Show measured facts, inferences, and missing evidence separately.
7. Show the typed experiment and deterministic policy validation.
8. Show verification logic; label the real follow-up rerun pending unless one
   has actually been measured and imported.
