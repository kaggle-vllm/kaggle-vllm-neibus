# Demo plan

The three-minute demo should show one real problem end-to-end:

1. Show dual-T4 environment.
2. Load two real runs.
3. Ask: "Why did TP=2 underperform TP=1 at this concurrency?"
4. Show Nemotron invoking read-only tools.
5. Show evidence-backed diagnosis.
6. Show the proposed experiment.
7. Show deterministic policy validation.
8. Show a measured rerun and before/after verification.
